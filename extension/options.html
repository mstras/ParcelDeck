ParcelDeck for Amazon

  1. In ParcelDeck, open ⚙︎ and copy the Server URL and Import key from the Chrome extension row.
  2. Paste them below and click Save & test. Chrome will ask to allow access to your ParcelDeck site.
  3. Stay signed in to amazon.com in this Chrome profile.

Only Amazon order and tracking pages are read, using the Amazon sign-in already in this browser. Your Amazon password is never seen or stored. Data goes only to the ParcelDeck URL above.
