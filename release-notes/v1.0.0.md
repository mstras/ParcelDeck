Self-hosted package tracker for every carrier. It uses the 17TRACK API (3,000+ carriers) and keeps your data on your own server.

### Tracking
- Add any tracking number and the carrier is detected automatically, with manual override from a searchable carrier list
- Covers USPS, UPS, FedEx, DHL, Amazon Logistics, OnTrac/LaserShip, AliExpress/Cainiao, YunExpress, China Post, Yanwen, 4PX, Royal Mail, Canada Post and more
- Multi-leg timeline: international shipments show the origin carrier and the last-mile carrier together (e.g. Cainiao → USPS)
- Active, Delivered and Archived views, labels, bulk add, estimated delivery date when available
- Background refresh (`POLL_MINUTES`), plus a signed 17TRACK webhook for near-instant updates

### Gmail import
- Watches Gmail over IMAP with an app password, read-only (never marks mail as read)
- Adds confident matches automatically (UPS `1Z`, USPS with check digit, AliExpress `LP`, Amazon `TBA`, international postal, carrier links, "Tracking number:" text)
- Ambiguous numbers go to a "Found in email" review box; dismissed ones aren't suggested again
- `EMAIL_MODE=auto|review|off`, configurable lookback and scan interval

### Notifications
- Push or email alerts through Apprise (ntfy, Pushover, Telegram, Discord, email…) on status changes and new email imports

### Security
- Username/password login in front of every page and API call
- 30-day sessions that survive restarts; changing the password signs out all devices
- Per-IP lockout after 5 failed attempts (15 minutes)

### Deployment
- Single container, SQLite in `./data`
- Image: `ghcr.io/mstras/parceldeck:1.0.0` (also `:latest`)
- Can be added to your phone's home screen like an app

### Known limitations
- Each new tracking number uses 1 17TRACK quota (refreshes are free)
- Packages delivered by Amazon itself often have no tracking number in the email
- Gmail app passwords don't work on Google Workspace accounts
