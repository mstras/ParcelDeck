Bug-fix release.

### Fixes
- **Delivery estimates showed one day early** in US time zones (e.g. a Saturday ETA displayed as Friday). Estimates are calendar dates and are now shown as such.
- **"Found in email" on phones:** the ✕ dismiss button was pushed off-screen when the tracking number was long.

### Changes
- Sign-out button is now a ⏻ power icon so it isn't confused with refresh.
- README now includes screenshots.

### Upgrade
`docker compose pull && docker compose up -d` (or pin `ghcr.io/mstras/parceldeck:1.0.1`). No config or database changes.
