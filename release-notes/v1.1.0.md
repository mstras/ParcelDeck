### New: Amazon orders via Chrome extension
Amazon has no API for your own orders, and its shipping emails often leave out the tracking number. The new **ParcelDeck for Amazon** extension uses the Amazon sign-in already in your Chrome to find your shipments and send them to ParcelDeck.

- Checks your last 30 days of orders every hour while Chrome is open
- Reads each shipment's carrier and tracking ID (UPS `1Z…`, USPS, Amazon `TBA…`, …) from its tracking page, once per shipment
- Packages are labeled with the item name and get an **Amazon ↗** link back to the order
- Pages you open yourself on Amazon are imported too
- Your Amazon password is never seen or stored; the toolbar icon shows **!** if you're signed out

**Install:** download `parceldeck-extension-v1.1.0.zip` below, unzip it, then in `chrome://extensions` turn on Developer mode → **Load unpacked**. Paste the Server URL and Import key from ParcelDeck ⚙︎ into the extension's settings.

### Server
- New import endpoint (`/api/import/amazon`) protected by an **import key** that can only add packages. Shown in ⚙︎ with *Copy key* / *New key*; can be pinned with `IMPORT_TOKEN`.
- Packages show where they came from: ✉︎ Gmail, 🛒 Amazon.

### Upgrade
`docker compose pull && docker compose up -d`. The database updates itself; no config changes needed.

Note: automating your Amazon account is against Amazon's terms. The extension keeps to roughly human browsing levels from your own browser, but use it knowing that.
